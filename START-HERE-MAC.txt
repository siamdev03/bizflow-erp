BIZFLOW ERP — START HERE (MacBook Air M2)

1) Install Node.js 20+ and make sure MongoDB is running, OR create a MongoDB Atlas database.
2) Open Terminal and cd into the extracted bizflow-erp folder.
3) Run:
   npm install
   npm install --prefix server
   npm install --prefix client
4) Configure:
   cp server/.env.example server/.env
   Edit server/.env and set MONGODB_URI and a strong JWT_SECRET.
5) Load demo data (WARNING: clears BizFlow collections in the selected DB):
   npm run seed
6) Start both apps:
   npm run dev
7) Open http://localhost:5173

Demo login:
  admin@bizflow.local
  Admin@12345

API health:
  http://localhost:4000/api/health

See README.md for full setup, features, API routes and troubleshooting.
